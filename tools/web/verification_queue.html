start_verify.sh builds a local virtualenv on first run, installs the dependencies, starts the app and opens your browser. Pass a port if 8765 is taken: ./start_verify.sh 8899. If pip ever says externally-managed-environment, that is a bare pip install outside the virtualenv — use the script. On Debian or Ubuntu, No module named venv means sudo apt install python3-venv. On Windows, use Git Bash or WSL. If nothing opens and there is no error, the server is already running: go to 127.0.0.1:8765 yourself.

Packets A and B sit side by side with differences highlighted and every estimate linked to PubMed or its DOI, with that record's red-team flags at the top. Press p to promote, r to reject with a reason, n to skip. Promotion re-checks schema, vocabulary, units and quote-plus-location before writing, and only ever writes to records/verified/. Commit and push that folder whenever you stop.

Four things only you can settle

Units
Sensitivity and specificity are stored as proportions — 0.82, never 82. The tooling enforces it, but check what you promote.
Direction
lr_positive means the finding is present, lr_negative means it is absent. A few packets inverted this where the source reported the negative sign. Fix it in the draft column.
Composites
An estimate for “JVD at rest or inducible” is not an estimate for jugular venous pressure alone. Either drop it or keep the COMPOSITE: prefix so the card says so.
Empty rows
Five estimates carry no numeric field at all — a kappa or a prevalence only. Delete the row and keep the text in the notes.
