How to do this fast · and the one rule that matters
  1. Tap only the keepers, then bulk the rest. Go down the case tapping anything that is not irrelevant — Relevant, Marginal, or Not an item — then use Mark the remaining irrelevant in the bar below. Ten or so decisions per case instead of forty. Catch the headings and citation lines with Not an item on the way down: the bulk action would otherwise count them as irrelevant recommendations, which counts against the arm unfairly.
  2. Finish a case before you stop. This is a comparison between arms, so being systematically strict cancels out — drifting strictness does not. Every case holds items from all three arms, so finishing one in a sitting means any drift hits all arms equally. A case is five to ten minutes.
  3. Decide this one thing first. A recommendation that is correct medicine but not a bedside act — send a troponin, get a CT, start telemetry — is it Irrelevant or Marginal? It comes up often enough that changing your mind halfway is the biggest risk to the result. This is a bedside card, so Irrelevant is the defensible answer; either way, pick now.
  4. Calibrate on the first case, then stop deliberating. Take it slowly to fix your thresholds (those scores still count), then do not revisit earlier cases. Inconsistency costs more than strictness.
